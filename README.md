# SNS 記録帳

X・Threads・note のフォロワーやインプレッションを、手帖のように一日ずつ残していく Web アプリです。数字の大小よりも「続けてきた日々」が目に入るようにつくっています。

**https://flawy0025.github.io/sns-kirokucho/**

## できること

- その日のフォロワー数・インプレッション（閲覧数）・投稿数・反応などを記録する
- 7日・30日のサマリー、媒体ごとのカード、推移のグラフで見返す
- アナリティクス画面のスクショから数字を読み取って、入力欄に入れる
- 使わない SNS を外す
- この2週間に書いた日をスタンプで見る
- 色を「手帖」「霧」「夜」の3つから選ぶ（選んだ色は保存した画像にも反映されます）
- ダッシュボードのまとめを画像（1080×1350）で保存する
- （上級者向け）自分で用意した GitHub の自動取得リポジトリとつなぎ、開いたときに新しい記録を取り込む
- 記録を JSON・CSV で書き出す / 取り込む
- ホーム画面に追加して、アプリのように使う（通信がなくても開けます）

## 記録の保存について

- 記録は、使っているブラウザの中（localStorage）だけに保存されます。サーバーには送られず、ほかの人からは見えません。
- そのため、スマホと PC など別の端末では記録は共有されません。移すときは「書き出す」→「取り込む」を使ってください。
- ブラウザのデータを消すと、記録も消えます。ときどき「書き出す」でバックアップしてください。
- iPhone の Safari では、しばらく開かなかったサイトのデータが消されることがあります。ホーム画面に追加して使うのがおすすめです。
- iPhone では、ホーム画面に追加したアプリと Safari で記録が別々に保存されます。Safari で入れた記録は「書き出す」→ アプリで「取り込む」で移せます。

## スクショの読み取りについて

- 画像は端末の中で読み取ります（[Tesseract.js](https://github.com/naptha/tesseract.js) による文字認識）。画像がどこかに送られることはありません。
- 初回だけ、読み取り用のプログラムと日本語のデータ（2MB ほど）を jsDelivr から読み込みます。
- 読み取りは完全ではありません。入った数字を確かめてから保存してください。画面にあった数字は候補として表示され、タップして入れることもできます。

## ファイル

| ファイル | 中身 |
| --- | --- |
| `index.html` | 画面とデザイン |
| `app.js` | 記録・グラフ・書き出しなどの動き |
| `ocr-parse.js` | 読み取った文字から数字を拾う部分 |
| `sw.js` | 通信がなくても開けるようにする仕組み |
| `manifest.webmanifest`, `icons/` | ホーム画面に追加したときの名前とアイコン |
| `vendor/d3.min.js` | グラフ用のライブラリ（[D3.js](https://d3js.org/)、ISC ライセンス） |
