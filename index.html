SNS 記録帳

X・Threads・note の数字を記録して、伸びた日を見つけよう。

はじめに

X・Threads・note の数字を、毎日ひとこまずつ残していく記録帳です。

  1. 1. 数字を入れる「記録する」から、その日のフォロワーやインプレッションを入れます。使わない SNS は「設定とデータ」で外せます。
  2. 2. スクショから読み取るアナリティクス画面のスクショを選ぶと、数字を読み取って欄に入れます。読み取りはこの端末の中で行います。
  3. 3. ホーム画面に置くホーム画面に追加すると、アプリのように開けます。記録はときどき書き出して保管してください。

記録はこのブラウザの中だけに保存されます。どこかに送られたり、ほかの人に見られたりすることはありません。

サンプルの記録を表示しています（あなたの記録ではありません）。

記録はこのブラウザの中にしかありません。端末の故障やブラウザのデータ削除に備えて、ときどき書き出しておきましょう。

iPhone では、共有ボタンから「ホーム画面に追加」すると、アプリのように開けます。Safari のまま使うと、しばらく開かなかったときに記録が消えることがあるので、ホーム画面からの利用がおすすめです。

設定とデータ

記録はこのブラウザの中だけに保存されています。

使う SNS

使わないものを外すと、カードや入力欄から消えます。入れた記録は消えません。

書き出す（バックアップ）

すべての記録をファイルに保存します。JSON は、別の端末やブラウザで取り込み直せます。

取り込む

書き出した JSON か CSV を読み込みます。同じ日付の記録は上書きされます。

アプリとして使う

ホーム画面に追加すると、アプリのように開けて、通信がなくても記録を見られます。

iPhone は Safari の共有ボタン →「ホーム画面に追加」、Android は Chrome のメニュー →「ホーム画面に追加」です。

記録をすべて消すときは、先に書き出しておくと安心です。
