SNS 記録帳

数字よりも、続けてきた日々を見る手帖。

はじめに

ようこそ、SNS 記録帳へ

X・Threads・note の数字を、一日一ページずつ残していく手帖です。

  1. 1. 数字を書きとめる「今日のページを書く」から、その日のフォロワーや届いた数を入れます。使わない SNS は「設定とデータ」で外せます。
  2. 2. スクショから読み取るアナリティクス画面のスクショを選ぶと、数字を読み取って欄に入れます。読み取りはこの端末の中で行います。
  3. 3. ホーム画面に置くホーム画面に追加すると、アプリのように開けます。記録はときどき書き出して保管してください。

記録はこのブラウザの中だけに保存されます。どこかに送られたり、ほかの人に見られたりすることはありません。

サンプルのページを表示しています（あなたの記録ではありません）。

記録はこのブラウザの中にしかありません。端末の故障やブラウザのデータ削除に備えて、ときどき書き出しておきましょう。

iPhone では、共有ボタンから「ホーム画面に追加」すると、アプリのように開けます。Safari のまま使うと、しばらく開かなかったときに記録が消えることがあるので、ホーム画面からの利用がおすすめです。
ホーム画面のアプリと Safari では記録が別々に保存されます。Safari で入れた記録は「書き出す」→ アプリで「取り込む」で移せます。

設定とデータ

記録はこのブラウザの中だけに保存されています。

使う SNS

使わないものを外すと、カードや入力欄から消えます。書いた記録は消えません。

書き出す（バックアップ）

すべての記録をファイルに保存します。JSON は、別の端末やブラウザで取り込み直せます。

取り込む

書き出した JSON か CSV を読み込みます。同じ日付の記録は上書きされます。

自動取得とつなぐ

上級者向け

GitHub に、自分で自動取得の仕組み（X・Threads の数字を毎日保存するリポジトリ）を用意している人向けです。つなぐと、記録帳を開いたときに新しい記録を取り込みます。

鍵は、そのリポジトリだけを読める読み取り専用のもの（Fine-grained token・Contents: Read-only）を使ってください。鍵はこの端末のブラウザの中にだけ保存され、GitHub に記録を読みに行くときにしか使いません。書き出すファイルや保存する画像にも入りません。

とつながっています

取り込むのは空欄でない数字だけです。手で入れた note の数字やメモ、取り込んだあとに手で直した数字はそのまま残ります。つないでいる間は、消した記録も次に開いたときに取り込み直されます。

アプリとして使う

ホーム画面に追加すると、アプリのように開けて、通信がなくても記録を見られます。

iPhone は Safari の共有ボタン →「ホーム画面に追加」、Android は Chrome のメニュー →「ホーム画面に追加」です。

記録をすべて消すときは、先に書き出しておくと安心です。
